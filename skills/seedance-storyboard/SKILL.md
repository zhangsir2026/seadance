# 服装品牌即梦视频提示词生成器

专为服装品牌设计，根据选择的变量，生成一条完整的 Seedance 视频提示词。

**核心目标：服装细节完全保持不变，动作自然流畅，画质极致清晰。**

---

## 固定常量（每条提示词都包含）

以下内容在所有提示词中固定出现，不可更改：

```
8K 超高清画质，面部稳定不变形，五官清晰，人体结构正常，比例自然，动作不僵硬。不改变衣服印花、细节、颜色、款式、纹理、位置、图案等，衣服细节均与原图一致，无任何变形、替换、修改、增减，画面极度稳定统一；道具、场景完全固定不变。
```

## 工作流程

### 第一步：引导用户选择变量

依次询问以下 4 个变量（用序号列表展示选项）：

**① 人数**
- 1️⃣ 1人
- 2️⃣ 2人

**② 衣服风格**
- 1️⃣ 牛仔外套
- 2️⃣ 羽绒服
- 3️⃣ 连衣裙
- 4️⃣ 户外风
- 5️⃣ 手动输入

**③ 道具**
- 1️⃣ 橄榄球
- 2️⃣ 滑板车
- 3️⃣ 小喇叭
- 4️⃣ 棍子
- 5️⃣ 无道具
- 6️⃣ 手动输入

**④ 年龄段**
- 1️⃣ 小朋友（默认）
- 2️⃣ 手动输入

### 第二步：展示动作运镜列表

根据用户选择的【人数 × 道具】组合，从下方数据库中调取对应的 10 条动作+运镜方案，展示给用户选择：

> **动作运镜方案（共10种，请选1种）：**
> 1. [方案描述]
> 2. [方案描述]
> ...

同时提供：
- 输入 **A** 查看 20 种常用动作列表
- 输入 **B** 查看 20 种常用运镜列表
- 输入数字 **1-10** 直接选择方案
- 输入**自定义**手动描述动作和运镜

### 第三步：生成最终提示词

将以下内容拼合为一段完整提示词：

```
[固定常量]，[年龄段]，[人数描述]，[衣服风格]，[道具描述]，[动作+运镜]。
```
